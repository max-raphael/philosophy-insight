### Programmatic Access

#### **Text Download URLs**
Format: `http://www.gutenberg.org/cache/epub/[ID]/pg[ID].txt`
Example: `http://www.gutenberg.org/cache/epub/5827/pg5827.txt`

Also available:
- HTML format
- EPUB format
- Kindle format

#### **Metadata & Feeds**
Available at: `http://www.gutenberg.org/cache/epub/feeds/`

- `today.rss` (3.3KB) - Daily new releases
- `pg_catalog.csv` (20MB) - Complete catalog CSV
- `pgmarc.xml` (285MB) - Detailed MARC metadata
- `rdf-files.tar.bz2` (119MB) - RDF metadata
- `txt-files.tar.zip` (10GB) - All text files (massive)

#### **API & Scraping Policies**
⚠️ **Important**: Project Gutenberg explicitly prohibits automated scraping of their website.

**Allowed Methods**:
1. Use `wget` with rate limiting (`-w 2` for 2 second delays)
2. Download their complete mirror via official instructions
3. Download the catalog CSV and use direct file URLs
4. Parse their RDF metadata feeds

**Recommendation**: Download `pg_catalog.csv` once, filter for philosophy books, then use direct file URLs to download texts.

### Quality Considerations
- **Text Quality**: Plain text format, generally good OCR quality
- **Structure**: Varies by book - some well-structured, some just paragraphs
- **Metadata**: Excellent - includes author, title, subject, language, download counts
- **Licensing**: All public domain, no restrictions

## 4. INTERNET ARCHIVE / OPEN LIBRARY

### Overview
- Open Library: 196,618 philosophy works
- Massive collection including out-of-print books
- Controlled Digital Lending (CDL) system
- Internet Archive broader collection includes scanned philosophy texts

### Philosophy Subject Collection
Website: https://openlibrary.org/subjects/philosophy
- 196,618 total works tagged as philosophy
- Mix of public domain and in-copyright works
- Lending system: borrow books for 1-2 weeks (like a library)

### Programmatic Access

#### **Open Library Books API**
Documentation: https://openlibrary.org/dev/docs/api/books

**Multiple API endpoints**:
1. **Search API** (recommended)
2. **Works API** - by Work ID
3. **Editions API** - by Edition ID
4. **ISBN API** - by ISBN
5. **Books API** (legacy)

**Example URLs**:
- Works: `https://openlibrary.org/works/OL45804W.json`
- ISBN: `https://openlibrary.org/isbn/9780140328721.json`

**Data Available**:
- Metadata: title, author, publisher, subjects, identifiers
- Cover images
- Table of contents
- Full text (for public domain works)

#### **JSTOR Early Journal Content**
- Internet Archive hosts JSTOR's pre-1923 philosophy journals
- Free access to early academic philosophy papers
- **Note**: Specific collection URL was not accessible during research

### Quality & Access Considerations
✅ **Massive collection** - Hundreds of thousands of philosophy titles
✅ **API available** - Good programmatic access
✅ **Free for public domain** - No cost for pre-1928 works
⚠️ **Mixed licensing** - Must filter for public domain only
⚠️ **Quality varies** - Some are poor scans
⚠️ **Lending system** - In-copyright works require "borrowing" (not useful for our app)

💡 **Recommendation**: Good supplementary source, but filter carefully for public domain works only

## 5. WIKISOURCE (Collaborative Wiki Platform)

### Overview
Website: https://en.wikisource.org
- Wikipedia's sister project for source texts
- Collaborative transcription of public domain works
- Philosophy portal with curated collections

### Content
- Major philosophy texts organized by era/philosopher
- Both complete works and excerpts
- Multiple languages available
- **Access was blocked during research (403 error)** - but known to have extensive collection

### Key Features
✅ **Free access** - All content public domain or free license
✅ **Good quality** - Community-reviewed transcriptions
✅ **Structured** - Wiki markup makes parsing easier
✅ **Citations** - Includes source information

### Programmatic Access
- **MediaWiki API** available (standard Wikipedia API)
- Can query by title, category, author
- Export in multiple formats (wikitext, HTML, plain text)

**Example Categories**:
- Category:Philosophy
- Author pages (e.g., Author:Bertrand_Russell)

### Limitations
⚠️ **Incomplete works** - Some texts are partial transcriptions
⚠️ **Quality varies** - Community-edited, not professionally proofread
⚠️ **Structure varies** - Inconsistent formatting between texts

💡 **Use Case**: Good for filling gaps in Gutenberg/Standard Ebooks collection

## APPENDIX: API ENDPOINTS & FEEDS

### Project Gutenberg
- Catalog: `http://www.gutenberg.org/cache/epub/feeds/pg_catalog.csv`
- RSS: `http://www.gutenberg.org/cache/epub/feeds/today.rss`
- Text: `http://www.gutenberg.org/cache/epub/[ID]/pg[ID].txt`
- EPUB: `http://www.gutenberg.org/ebooks/[ID].epub3.images`

### Standard Ebooks
- OPDS: `https://standardebooks.org/feeds/opds/all` (requires membership)
- Atom: `https://standardebooks.org/feeds/atom/new-releases` (free)
- RSS: `https://standardebooks.org/feeds/rss/new-releases` (free)
- GitHub: `https://github.com/standardebooks/[author]_[title]`

### Open Library
- API: `https://openlibrary.org/api/books?bibkeys=ISBN:[isbn]&format=json`
- Works: `https://openlibrary.org/works/[ID].json`
- Search: `https://openlibrary.org/search.json?q=[query]`

### Wikisource
- API: `https://en.wikisource.org/w/api.php`
- Standard MediaWiki API calls
- Export: Add `?action=export` to page URL
